# 계층 턴과 메인 사건

## 배경

설정 턴이 0일 수 있고, 카드 소진으로 계층을 일찍 끝낼 수도 있다. 각 계층의 마지막 메인 사건이 다음 계층의 유산 분기를 정하는 경우가 있다.

## 결정

세션은 현재 계층 순서와 그 계층에서 사용한 턴을 관리한다. 계층 진입 시 고유한 메인 사건의 수를 세어 턴을 확보한다. 메인 카드는 사건 번호 순서대로 진행한다. 설정 턴을 다 쓴 뒤 남은 메인 카드는 턴 카운트를 늘리지 않고 처리한다.

## 검토한 방식과 영향

누적 턴을 고정 길이로 나누는 방식은 0에서 계산할 수 없고, 일찍 끝난 계층과 메인 카드가 연장된 계층의 경계를 표현하기 어렵다. 설정 턴에 맞춰 바로 넘기면 마지막 메인 사건의 유산 분기가 사라질 수 있다. 선택한 방식에서는 계층 순서와 계층 내 사용 턴을 진행 세이브에 담아 이어하기를 복원한다.
