# 게임 로직과 UI의 연결 경계

## 배경

프론트 담당자가 카드 화면과 입력을 만들고, 백엔드 담당자가 카드 선택과 스탯, 계층 진행, 저장을 구현한다. 스와이프 시제품에는 카드 공급과 스탯 반영이 함께 들어 있어 통합할 때 동일한 선택을 두 번 처리할 수 있다.

## 결정

게임 규칙과 저장은 세션에서 처리한다. 프론트의 입력을 Unity 쪽 연결 지점으로 받고, UI는 세션에서 확정한 현재 카드와 스탯, 계층 전환 결과를 표시한다.

## 검토한 방식과 영향

UI의 자체 카드 공급과 스탯 반영을 실제 플레이에도 그대로 쓰면 프론트와 세션이 서로 다른 진행 결과를 가질 수 있다. 통합에서는 UI의 선택 미리보기와 확정 결과를 구분하고, 확정 입력 한 번이 저장까지 한 번만 진행되는지 확인한다.
