# 진행 상태

2026-11-12 기준 `JMS` 작업 트리를 소스로 확인했다. Unity 플레이, 빌드, 패키지 복원은 검증하지 않았다.

## 코드에서 확인한 것

- CSV에는 계층 5개, 사건 20개, 카드 변형 36종이 있다. 현재 행의 사건 유형은 모두 `main`이다.
- 카드 조회, 선택에 따른 스탯·플래그·사건 기록 변경, 로컬 JSON 저장과 기존 체크포인트 수동 복원 코드가 있다.
- 개발용 테스트 씬에는 자동 검사와 고정 카드 수동 화면이 있다. 테스트가 참조하는 일부 멤버가 현재 모델과 달라 컴파일 및 실행 결과는 확인되지 않았다.
- `origin/JSW`에서 별도로 스와이프와 카드 화면 시제품을 확인했다. `JMS` 작업 트리에서는 해당 코드를 실행하는 씬이 없다.

## 남은 작업

1. 다음 카드 선택을 구현한다. 새 게임의 첫 카드부터 메인 사건 순서, 유산 분기, 설정 턴과 메인 카드 예약을 연결한다.
2. 계층 진입 체크포인트와 저장 후 `CasteChanged`를 연결한다. 스탯 0 또는 100에서 체크포인트로 돌아가고, 이전 JSON 형식의 이어하기도 확인한다.
3. 테스트 스크립트와 게임 모델의 불일치를 해소한다. 임시 저장으로 한도 0, 계층 조기 전환, 체크포인트 복원과 이벤트 순서를 검증한다.
4. 프론트가 만든 UI에 좌우 선택 진입점과 카드·계층 변경 알림을 연결한다. 스와이프 한 번이 선택 한 번으로 이어지는지 두 담당 영역을 함께 검증한다. 엔딩 플래그의 최종 판정과 표시 규칙을 확인한다.
