# 해결이 필요한 문제

## 테스트 스크립트와 런타임 모델의 API 불일치

현재 작업 트리에서 `Test.cs`는 `ProgressData.currentVariantId`, `GameState.HasSeenEvent()`, `InitEventHist()`, `cardHistory` 생성자 인자를 참조한다. 런타임 모델의 실제 멤버와 이름이 다르다. 두 종류의 스크립트가 같은 Unity 어셈블리에 포함되므로 테스트 씬을 빌드 목록에서 제외해도 컴파일을 막는다. 소스 대조에서 확인했으며, 수정은 진행 기능 구현 때 저장 모델과 기존 검증을 함께 맞추는 작업이다.

## 플레이 씬 연결 공백

현재 빌드 설정으로 시작하면 카메라와 조명만 있는 씬을 열게 된다. 개발용 씬은 스와이프가 아닌 테스트 버튼으로 세션을 호출한다. 스와이프 시제품이 있는 `origin/JSW`와 현재 진행 코드의 연결은 확인되지 않았다. 실제 플레이 경로를 검증하려면 사용할 씬과 입력 연결을 결정하고, 한 번의 선택이 한 번만 처리되는지 확인해야 한다.
