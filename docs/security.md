# 플레이 데이터 보관

오프라인 전용 게임이다. 플레이어 계정, 클라우드 저장, 플레이 기록 전송 없이 기기에서 운영한다. 앱에서 발급하거나 회전할 로그인 자격 증명은 없다.

| 주체 | 읽거나 쓸 수 있는 데이터 | 범위 |
| --- | --- | --- |
| 일반 플레이 세션 | 현재 카드, 스탯, 플래그, 사건 기록, 체크포인트 | 실행 환경의 Unity 사용자 데이터 경로 |
| 개발용 테스트 세션 | 자동 검사와 수동 데모용 저장 파일 | 검사마다 만든 임시 디렉터리 |

현재 세이브는 평문 JSON이다. 진행 기록을 테스트 출력이나 공유 자료에 넣어야 할 때는 테스트가 만든 저장 파일을 사용한다. 개발용 씬은 일반 세이브를 여는 `GameManager`가 비활성화되어 있어야 한다.

현재 로더는 잘못된 JSON과 필수 데이터 누락을 오류로 보고한다. 없는 파일은 새 세션의 조건이다. 손상된 파일을 없는 파일과 같은 경우로 처리하면 진행 상태를 덮어쓸 수 있다.

현재 검사 결과는 Unity 콘솔에서 확인한다. 플레이어의 행동을 원격으로 감사하거나 수집하는 기능은 프로젝트 범위에 없다.
